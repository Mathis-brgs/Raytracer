# 0003 — Catch2

## Status

Accepted

## Context

The project follows TDD. A test framework must work with CMake/CTest and be easy to learn for a contributor new to C++.

Alternatives considered:
- **Google Test (gtest)** — widely used; more verbose setup, macro syntax is less readable.
- **doctest** — single-header, minimal overhead; smaller community and fewer integrations.
- **Boost.Test** — full-featured; depends on the whole Boost library, which is a heavy dependency.

## Decision

Use Catch2 v3.7.1, pinned via `FetchContent_Declare` in `CMakeLists.txt`. Tests are discovered automatically by CTest through `catch_discover_tests`.

## Consequences

- `REQUIRE` and `SECTION` macros read like plain English, making tests easy to write and review for someone new to C++.
- Catch2 integrates with CTest with one `include(Catch)` line; no glue code needed.
- The version is pinned (`v3.7.1`), so builds are reproducible and upgrades are explicit.
- The source is downloaded at configure time (`FetchContent`); first build requires a network connection and takes longer.
- Catch2 v3 is a compiled library (not header-only), which adds a small compile step compared to doctest.
